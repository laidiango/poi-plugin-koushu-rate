# poi-plugin-koushu-rate

列出所有可改修装备，点击装备后自动计算不确保改修的数学期望与确保改修消耗的对比，并给出推荐。

## 功能

- 弹出窗口展示全部可改修装备，装备图标内置在左侧展开框内，支持按名称搜索。
- 按周一至周日分类可改修日期，支持按日期筛选，全部模式下显示每日可改修标签。
- 装备按小口径主炮、中口径主炮等分类，支持分类筛选。
- 列表表头显示推荐星级（常规图 / 活动图），已按 NGA 攻略整理并内置。
- 搜索支持中文/日文混输模糊匹配，输入部分字符即可找到最相似装备。
- 定时从 akashi-list.me 更新装备分类与推荐标记，默认每 2 天自动检查，也可手动“更新数据”。
- 数据直接复用改修规划插件的静态数据；未安装改修规划时使用插件自带的同版本数据。
- 每个装备展开后分两级显示：
  - 第一级“0→5”默认收起，点击展开；0→1 至 4→5，成功率100%，不显示确保判断
  - 第二级“6→MAX”默认展开，包含 5→6 至 MAX→进化，成功率 95 / 90 / 82 / 77 / 67 / 62%
  - 第二级显示不确保期望与确保消耗对比，并推荐是否确保。
- 展开后的消耗装备列在“确保推荐”下方；装备类素材可点击，弹窗内按 kc-development-tools 同款数据反推该装备的可用开发配方，并提供打开网站入口。

## npm 码

在 poi 的 设置 → 插件管理 → 从 npm 直接安装 中填入：

poi-plugin-koushu-rate

需要该包已经发布到 npm 后才会生效。

## 本地安装

把 `poi-plugin-koushu-rate` 目录放到：

%APPDATA%\poi\plugins\node_modules\

并在 %APPDATA%\poi\plugins\package.json 的 dependencies 中加入：

"poi-plugin-koushu-rate": "1.3.0"

重启 poi 后，插件列表会出现“螺丝计算器”，点击后以弹出窗口打开。

## 数据来源

- 装备基础消耗、阶段资材：poi-plugin-kai-planner 的 static 数据（插件内置同名数据作为兜底）。
- 装备名称：优先读取 poi 的母港 master 数据，缺失时使用内置名称表。
- 开发配方数据与算法：kc-development-tools（SkywalkerJi，https://github.com/SkywalkerJi/kc-development-tools），按需联网获取并缓存 2 天。
